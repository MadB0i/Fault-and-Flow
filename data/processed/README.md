# data/processed

Pipeline output that the app loads at runtime. Only **small** files are committed
(limit: 5 MB per file, per `AGENTS.md`). Anything larger stays out of git and is
either fetched at build time or loaded from `/public`.

Every file here must be:

- Generated by a committed script (see `scripts/`), not hand-edited.
- Listed in [`docs/DATA.md`](../../docs/DATA.md) with its upstream source and license.
- Deterministic — same input produces byte-identical output.

## Naming

```
<dataset>_<resolution-or-step>.<format>
```

Examples reserved for later phases: `dem_assam_30m.bin`, `plates_pb2002.json`,
`quakes_ne_india_1900_2026.json`.

Phase 1 commits no data files — only this README.
